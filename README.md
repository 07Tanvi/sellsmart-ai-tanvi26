# SellSmart AI 🛍️

SellSmart AI is a simple AI-powered product listing generator for small businesses and online sellers.

## Features
- Generate catchy product titles
- Create product descriptions
- Write promotional captions
- Supports Instagram, Amazon, Etsy, and WhatsApp

## Built With
- HTML
- CSS
- JavaScript
- Ollama
- Qwen 2.5 1.5B

## How to Run
1. Make sure Ollama is running and `qwen2.5:1.5b` is installed.
2. Open a terminal in the project folder.
3. Run `python -m http.server 8001`.
4. Open `http://localhost:8001` in your browser.
5. Enter product details and click **Generate with AI**.

## Why Open-Source AI?
Running an open-weight AI model locally gives users more control over their data and reduces dependence on paid hosted AI APIs.
